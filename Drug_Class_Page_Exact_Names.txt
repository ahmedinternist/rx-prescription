DRUG CLASSES PAGE - EXACT TAB AND SUBPAGE NAMES
================================================

This file uses the exact English names currently displayed by the application.

IMPORTANT TERMINOLOGY
---------------------

Level 1 page title:        Drug classes
Level 1 left panel:        Major therapeutic groups
Level 1 right panel:       Detailed drug classes
All-classes button/page:   Detailed Drug Classes
Navigation button:         Back

The current application does NOT have a separate clinical "Subgroup" level.
Internally, the code calls the detailed classes SUBCLASSES, but the visible UI
name is "Detailed drug classes".

The exact current navigation structure is:

  Drug classes
    -> Major therapeutic groups
       -> [Major therapeutic group name]
          -> Detailed drug classes
             -> [Detailed drug class name]
                -> Medicines mapped to that detailed drug class

Major-group subpage navigation trail:

  Major therapeutic groups  >  [Major therapeutic group name]

Medicine-list subpage navigation trail:

  [Major therapeutic group name]  >  [Detailed drug class name]

Therefore, the medicine-list subpage is the third visible level. It is not
currently named "Subgroup" in the application.
